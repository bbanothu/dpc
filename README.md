# User DPC

Minimal Android device policy controller (`com.user.dpc`) provisioned as device owner via QR code.

- `app/` – source; build with `app/build.sh` (expects JDK + Android SDK under `~/dpc/tools`, signing key under `~/dpc/keys`)
- `make-dpc-qr.sh` – generates the provisioning QR code

Download the APK from [Releases](../../releases/latest).
